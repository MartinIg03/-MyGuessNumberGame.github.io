# Guess My Number!

A small browser game built with HTML, CSS, and vanilla JavaScript. Try to guess the randomly chosen number between 1 and 100 while keeping your score as high as possible.

## How to play

1. Open the game in your browser.
2. Enter a number and select **Check!**.
3. Follow the “Too High!” or “Too Low!” hint until you find the secret number.
4. Select **Again!** to start a new round.

You start each round with 50 points and lose one point for each incorrect guess. Your best score is shown during the current page session.

## Run locally

No installation or build step is required. Open `index.html` in a web browser, or serve the project directory with any local static web server.

## Project files

- `index.html` — game markup
- `style.css` — page styling
- `script.js` — game logic
